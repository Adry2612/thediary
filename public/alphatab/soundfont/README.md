# Sonivox SoundFont

`sonivox.sf2` is the general-MIDI SoundFont bundled with
[alphaTab](https://www.alphatab.net/) (`@coderline/alphatab`). It is used only by
the tab playback controls to synthesize the structured tablature. The
playback controls let the user choose acoustic steel (GM 25), nylon (GM 24)
or clean electric guitar (GM 27).

Source: `node_modules/@coderline/alphatab/dist/soundfont/sonivox.sf2`.
